# Ghootae Kim — Personal Website

Source for [cogaxis.net](https://cogaxis.net).

The live site is served by GitHub Pages from the `main` branch, with the custom domain set in `CNAME` (DNS managed in Cloudflare). Merging to `main` deploys the site.

## Files

- `index.html`: single-page personal website
- `assets/ghootae-kim.jpeg`: profile photograph
- `assets/book-cover.jpg`: book cover
- `CNAME`: custom domain for GitHub Pages
